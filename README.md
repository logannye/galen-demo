# Galen Clinical-Safety Demo

This repository contains a packaged build of the **Galen** clinical-safety
prediction demo.

The live demo is hosted at **[demo.usegalen.com](https://demo.usegalen.com)**
and is access-controlled. If you have an access code, you can sign in and
explore the system there.

The interactive demo previews a causal-ML system that predicts off-target
drug safety from chemical structure alone — the first commercial proof
point for the biomedical world model we are building at Galen.

For more information about Galen Health, see
**[usegalen.com](https://usegalen.com)**.

---

This repository is a packaged artefact; the development source lives in
private. Code, data, and configuration here are deliberately minimal —
authentication, model weights, secrets, and proprietary substrate files
are managed outside this repository.
